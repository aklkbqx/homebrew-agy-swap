# Homebrew tap for agy-swap

```bash
brew install aklkbqx/agy-swap/agy-swap
```

This repository is a thin Homebrew tap. The application source, release
artifacts, and canonical formula template live in the main repository.

Formula updates are published explicitly with each release and committed here
as a normal reviewable change. This tap intentionally does not depend on
GitHub Actions or scheduled synchronization.

Source, documentation, and releases: https://github.com/aklkbqx/agy-swap
